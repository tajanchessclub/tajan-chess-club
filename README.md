# ♟️ Tajan Chess Club

**Tajan Chess Club** is a student-created website designed to help students discover and join the school chess club.

The website provides a simple and welcoming way for students to learn about the club and submit their interest in joining.

## ✨ Features

- ♟️ Introduction to the Tajan Chess Club
- 📝 Easy way for students to join the club
- 📱 Simple and student-friendly design
- 🎨 Designed and developed by students

## 🛠️ Technologies & Libraries Used

- **HTML** – Website structure
- **CSS** – Styling and layout
- **Bootstrap5** – Responsive design and UI components
- **JavaScript** – Interactive functionality
- **EmailJS** – Sending student registration details by email
- **SweetAlert2** – Toast notification upon form submission
